# ⚔️ Classificador de Nível de Herói

Projeto desenvolvido em **Java** para praticar lógica de programação, métodos e estruturas condicionais.

## 🎯 Objetivo

O programa recebe a quantidade de **vitórias** e **derrotas** de um herói, calcula seu saldo e determina seu nível.

## 🏆 Classificação

| Saldo de Vitórias | Nível |
|---:|---|
| ≤ 10 | 🪨 Ferro |
| ≤ 20 | 🥉 Bronze |
| ≤ 50 | 🥈 Prata |
| ≤ 80 | 🥇 Ouro |
| ≤ 90 | 💎 Diamante |
| ≤ 100 | 🔥 Lendário |
| > 100 | 👑 Imortal |

## 💻 Tecnologias

- ☕ Java
- 🧠 Lógica de programação
- 🔀 Estruturas condicionais
- ⚙️ Métodos
- 📦 Variáveis e tipos primitivos

## 📌 Como funciona

O saldo é calculado através da fórmula:

```text
saldo = vitórias - derrotas
